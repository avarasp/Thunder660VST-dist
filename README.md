# Thunder660 Drums VST

Official distribution repository for **Thunder660 Drums VST** by **Force56 Audio Software**.

Thunder660 is a drum machine plugin based on the classic **Boss DR-660**, bringing its complete original sound set into a modern, straightforward software instrument.

It includes all **255 original drum and percussion sounds**, with individual pad volume, panning and tuning controls covering a **±24 semitone range (two octaves in either direction)**, plus the original factory drum kits with their **Pad Bank A and B** variations.

Thunder660 is designed as a **no-frills, plug-and-play drum machine**: load it in your DAW, pick a kit, and start making music.

## Formats

* **Windows:** VST3 and Standalone
* **macOS:** VST3, Audio Unit (AU) and Standalone
